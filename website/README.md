# WxLens website

This directory contains the dependency-free static landing page for WxLens.

Run `node website/serve.js`, then open `http://127.0.0.1:4173/website/`. Serving the repository
root allows the shared branding assets under `app/res/branding/` to resolve correctly.

The page intentionally describes WxLens as under active development and links downloads to the
project repository rather than implying that a finished public release exists.
